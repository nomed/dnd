# Cael Vesper — edizioni da tavolo e grimorio illustrato

Questa directory aggiuntiva ospita le due nuove edizioni di Cael Vesper, druido livello 2 (D&D 2024). Il dossier originale `../lev02.md`, il registro MCP e le immagini esistenti rimangono invariati.

## Due formati

- **Scheda da tavolo:** 2 pagine A4, valori attuali e risorse, incantesimi con tempo di lancio, gittata, tiro per colpire o TS, danno/effetto, concentrazione e riferimento XPHB.
- **Grimorio illustrato:** edizione estesa, una sezione illustrata per ciascun incantesimo, con dettagli, condizioni e riferimenti al manuale.

## Stato della pubblicazione

I PDF, gli HTML autonomi e il catalogo JSON sono stati generati e verificati localmente il 10 ottobre 2026. **Non sono ancora presenti in questo branch:** il connettore GitHub disponibile accetta solo file testuali UTF-8, mentre gli HTML incorporano immagini e i PDF sono binari. Non sostituire i PDF con versioni incomplete.

Pacchetto pronto per il caricamento: `Cael-edizioni-v1.zip`, contenente:
- `cael-scheda-tavolo.pdf`
- `cael-scheda-tavolo.html`
- `cael-grimorio-illustrato.pdf`
- `cael-grimorio-illustrato.html`

- `provenienza.json`

## Criteri

- Le regole vengono dal server MCP Dnd, fonti XPHB 2024; la scheda originale fornisce le scelte del personaggio.
- Guidance rimane proposta da confermare; le quattro forme Wild Shape e il famiglio non sono stati inventati.
- Le capacità del Circolo delle Stelle sono future, dal livello 3.
- Le regole del Dominio Oscuro restano separate dalle regole XPHB.
